Artex is a self-hosted, AI-driven autonomous penetration testing system built on a multi-agent LLM architecture. A planner agent decomposes targets into exploration goals while worker agents execute real tooling — bash, HTTP, nmap, and more — recording every request and finding in a dual-graph database. The entire system ships as a single Go binary with an embedded Next.js dashboard.

## What Artex Does

Artex orchestrates a team of LLM-powered agents to autonomously explore web targets, map assets, and identify vulnerabilities — all without manual guidance after the initial task is created.

<CardGroup cols={3}>
  <Card title="Dual-Graph Engine" icon="diagram-project">
    A global **Asset Graph** tracks discovered infrastructure while a per-task **Exploration Graph** records the reasoning chain: goals → intents → facts → findings.
  </Card>
  <Card title="Human-in-the-Loop" icon="user-shield">
    An intercept/approval gate pauses destructive tool calls for human review before execution. Full MITM traffic recording captures every request.
  </Card>
  <Card title="Extensible Tooling" icon="puzzle-piece">
    Extend agents with custom skills, MCP servers (Streamable HTTP or SSE), and custom tools. Sync assets from ScopeSentry for seamless recon hand-off.
  </Card>
</CardGroup>

## Key Highlights

<Steps>
  <Step title="Create a task">
    Point Artex at a target scope — a domain, IP range, or list of URLs. The goals agent automatically decomposes your objective into concrete exploration targets.
  </Step>
  <Step title="Watch agents explore">
    The planner dispatches intents to worker agents. Each worker uses real tools (bash, HTTP clients, nmap, browser automation) and writes discoveries back to the graph.
  </Step>
  <Step title="Review findings">
    Vulnerability findings appear in the dashboard with full lineage: which intent produced them, what traffic was captured as evidence, and which assets are affected.
  </Step>
  <Step title="Retest and report">
    Trigger the built-in retest agent to verify fixes. Export findings as a structured report or receive real-time push notifications to Slack, Telegram, email, and more.
  </Step>
</Steps>
